# 🎬 Unfinished Love Multimedia

স্বাগতম! এটি **Unfinished Love Multimedia**-এর অফিসিয়াল পোর্টফোলিও ওয়েবসাইট। এখানে আমাদের সৃজনশীল কাজ এবং মাল্টিমিডিয়া সার্ভিস সম্পর্কে বিস্তারিত জানতে পারবেন।

## ✨ বৈশিষ্ট্যসমূহ (Features)
* **Modern UI:** গ্লাস-মরফিজম এবং ডার্ক মোড ডিজাইন।
* **Bouncy Scroll Animation:** স্ক্রল করার সময় চমৎকার এবং স্মুথ অ্যানিমেশন।
* **Responsive:** মোবাইল, ট্যাবলেট এবং পিসি—সব ডিভাইসের জন্য উপযোগী।
* **Fast Loading:** খুব দ্রুত লোড হওয়ার জন্য অপ্টিমাইজ করা কোড।

## 🛠 প্রযুক্তি (Technologies Used)
* **HTML5:** কাঠামোর জন্য।
* **CSS3:** আধুনিক ডিজাইন এবং অ্যানিমেশনের জন্য।
* **JavaScript (Intersection Observer):** স্ক্রল ডিটেকশন এবং ইন্টারেক্টিভ ইফেক্টের জন্য।
